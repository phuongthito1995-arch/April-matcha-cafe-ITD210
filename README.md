# ITD 210 Capstone Website Project

**Student Name:** Thi Phuong To  
**Milestone:** Contact Page / Final Pre-Submission Milestone  
**Website Title:** April Matcha Café

## Project Description
This website is a five-page matcha café capstone website created for ITD 210. The pages include Home, About, Menu, Gallery, and Contact. The design uses a calm green café palette, responsive layout, accessible navigation, hover interactions, and a clear story-driven concept.

## What Is New on This Page
This milestone adds a responsive and accessible contact page with Formspree integration, custom JavaScript validation, inline error messages, a live character counter, a FAQ accordion, an office-hours toggle, and a success confirmation state.

## Pages Included
- `index.html` — Home page with café introduction and hero content
- `about.html` — About page with the brand story and values
- `services.html` — Menu page with featured drinks, desserts, and experiences
- `gallery.html` — Gallery page with visual moodboard tiles
- `contact.html` — Contact page with validation, FAQ accordion, and success state
